Review: Boundary-aware LULC segmentation is still weak for wetland and transition zones

Your report already shows boundary improvement, but boundary recall remains weak. That means the model does not draw too many false boundaries, but it misses real class transitions. This is a good research gap.

Possible new idea:
Develop a dual-head boundary-aware LULC network for Sylhet:

One head predicts LULC classes.
One head predicts boundaries.
Use multi-scale boundary supervision.
Evaluate Boundary IoU, BF-score, and boundary recall at different buffer widths.
This directly extends the current report and connects well with BAS4Net.
